# Hand model (renders only)

`human_hand.py` poses `HandR.glb`, the rigged right hand from Meta's Quest hand-tracking samples (the same file ships
in Neuracore's `meta_quest_teleop/app_source/assets/`). It is Meta's asset and is not redistributed here: copy it into
this folder to rebuild `hand.png`. Without it the render shows the forearm only.
