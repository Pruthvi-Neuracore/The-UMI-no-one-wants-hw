# Quest Touch Pro controller (renders and assemblies)

`ebox.controller_envelope()` places `MetaQuestTouchPro_Right.stl` (Meta's Touch Pro controller, as posted from a Unity
project by MrTasselhof) upright in `quest_cradle`'s V, with its handle on 2 mm of foam. The model belongs to Meta and is not
redistributed here as a file (its placed shape does appear in the D405 assemblies and URDF meshes, for
visualisation only): put the STL in this folder to rebuild. Without it a stand-in of the same size is used.
